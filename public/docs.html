StreamVault API

A REST API for ad-free streaming resolution and full TMDB data access. All responses are JSON wrapped in a consistent envelope.

Base URL https://your-deployment.vercel.app
Authentication
Stream endpoints (/api/stream, /api/proxy) require no key.
All TMDB endpoints require your TMDB API key — pass it as ?tmdb_key=YOUR_KEY or as the X-TMDB-Key request header.
Get your free key at themoviedb.org.

All responses: {"success": true, "data": {...}} or {"success": false, "error": "..."}

GET/api/stream

Resolve a stream URL for a movie or TV episode. Returns a proxied HLS playlist URL.

ParamTypeRequiredDescription
idintegerrequiredTMDB ID of the movie or TV show
sintegeroptionalSeason number (TV only)
eintegeroptionalEpisode number (TV only, default 1)
GET /api/stream?id=550 → { "stream_url": "https://...", "proxied_url": "/api/proxy?url=..." }
GET/api/proxy

HLS proxy that rewrites segment URLs to pass through this server, bypassing CORS and hotlink restrictions.

ParamTypeRequiredDescription
urlstringrequiredURL-encoded upstream HLS/segment URL

GET /api/movie/550?tmdb_key=xxx

Combined endpoint: movie details + resolved stream URL in one request.

GET /api/movie/550/stream-info?tmdb_key=xxx → { "movie": {...}, "stream_url": "...", "proxied_url": "..." }
